What is driving it

Each input’s push on the log-odds. Left lowers risk, right raises it; a value sitting at the training average contributes nothing.

What the model receives
It under-predicts by about 5 points. On held-out 2017 arrivals the model averaged 33.6% against an actual 38.7%. Cancellation rose between the training and test periods. Treat the ranking as reliable and add a correction before using an absolute number for overbooking.
Fields you don’t touch aren’t neutral. Untouched inputs hold the dataset’s most common values, which describe a genuinely high-risk booking: Portuguese, Online TA, 90 days ahead. That is why the opening score is high.
